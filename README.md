<p align="center">
  <strong>Artemis' Thin Logs</strong>
</p>

<p align="center">
  Artemis' Thin Logs adds slimmer log, stem, and bamboo variants for more detailed building in Minecraft.
</p>

<p align="center">
  It focuses on decorative wood pieces that let you build narrower trunks, beams, poles, supports, and custom natural details while still matching vanilla wood sets.
</p>

  <img src="https://img.shields.io/badge/Minecraft-1.21.1-3C8527?style=for-the-badge&logo=minecraft&logoColor=white" alt="Minecraft 1.21.1">

</p>

<p align="center">
  Artemis' Thin Logs currently includes the following features:
</p>

<p align="center">
  &bull; Thin variants for overworld logs, nether stems, cherry, mangrove, and bamboo<br>
  &bull; Matching stripped thin variants<br>
  &bull; Support for placing carpets, moss carpet, leaves, snow layers, and snow blocks around thin logs<br>
  &bull; Decorative building options for custom trees, supports, beams, poles, and detailing
</p>

<p align="center">
  Artemis' Thin Logs is developed as part of the <strong>Intelligence Modding Team</strong>.
</p>
